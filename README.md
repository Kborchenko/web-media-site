# КОД ТЕХ

Корпоративный сайт КОД ТЕХ: компания, направления, вакансии, система развития команды и форма отклика.

## Публикация

Сайт статический и публикуется через GitHub Pages из корня ветки `main`.

## Важное ограничение

Формы отклика пока работают только в демонстрационном режиме: перед приёмом реальных заявок необходимо указать серверный endpoint в `main.js`. Контакт Telegram также будет добавлен позднее.
